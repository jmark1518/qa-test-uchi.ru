Тестовое задание для AQA стажёра в компании учи

Подготовка к работе
-------------------

Для начала работы убедитесь, что у вас установлены [node.js + npm](https://nodejs.org/en/download)

Установите зависимости проекта, выполнив команду:
```shell
npm ci
```

Запуск тестов
-------------

Запустите тесты с помощью команды:
```shell
npx playwright test
```



Дополнительно было сделано (для отображения в браузере):
```shell
npx playwright install chromium 
```

В итоге получилось:
```shell
npx playwright test

Running 3 tests using 1 worker
  3 passed (13.9s)
```
*при запуске точное итоговое время может отличаться
